# Документы для сравнения

- [Пример из задания, запись №1](reference-meeting-1.pdf) — официальный PDF-экспорт предоставленного Google Docs, без изменений.
- [Фактический результат ML, запись №1](model-meeting-1.pdf) — 10 поручений и 27 сегментов финального GPU-прогона. Сформирован через функцию DOCX нашего backend и перенесён в PDF. Это **неутверждённый проект**, с сохранёнными ошибками и предупреждениями; реальная дата встречи неизвестна.

Пример из задания расходится с аудио и не используется как пословный эталон WER. Эти файлы показывают ожидаемый образец и полученный автоматический результат, без подмены выхода модели вручную.

[Происхождение и хеши](pdf-provenance.json) · [Проверка страниц](pdf-qa.json). Оба документа созданы/получены на сервере; все страницы просмотрены после рендеринга. PDF здесь являются материалами для демонстрации, а пользовательский экспорт приложения остаётся DOCX.
