## Следующее действие: реальный speech-checkpoint

Все команды из корня проекта. Веса уже на диске; повторно их не скачивай:

```bash
export ASR_MODEL="$PWD/models/cpu-smoke/asr"
export DIARIZATION_MODEL_PATH="$PWD/models/cpu-smoke/diarization"
export ASR_DEVICE=cpu
export ASR_COMPUTE_TYPE=int8
export MPLCONFIGDIR="$PWD/eval/results/matplotlib"
eval/.venv/bin/python scripts/run_ml_checkpoint.py eval/audio/meeting-1.mp3 \
  --occurred-at 2026-09-23 --seconds 60 --min-speakers 2 \
  --output eval/results/meeting-1-speech-01.json
```

Дата здесь условная для технического теста, не установленная дата встречи. Если имя отчёта занято, выбери новое. Команда запускает реальные модели без Ollama; фоновых прогонов на момент передачи нет.

Первый технический рубеж достигнут: получены текст, реальные интервалы голосов и три speaker_id; сохранены длительности и конфигурация. Следующий шаг — сверить смены голосов и текст с аудио. `completed` доказывает исполнение, но не точность.

## Runtime и ограничения

Версии на текущем Mac: faster-whisper 1.2.1, ctranslate2 4.8.2, pyannote.audio 4.0.7, torch 2.14.0, torchaudio 2.11.0, torchcodec 0.16.0, huggingface_hub 1.32.0. Полный speech inference успешен через прямую передачу PCM тензора; путь чтения файла TorchCodec на Mac не работает с установленными FFmpeg библиотеками. Ревизии обеих моделей записаны в `models/cpu-smoke/manifest.json` и checkpoint.

Записи обрабатываются самостоятельно развёрнутыми моделями. Hosted OpenAI/NVIDIA inference не входит в согласованный основной путь. Токены остаются в локальном хранилище; содержимое не выводить. `models/`, `eval/audio/`, `eval/results/`, `eval/.venv/` игнорируются Git.
