## Следующий запуск

После отчёта GPU останавливается по просьбе пользователя. Файлы, модели, `.env` и база остаются на диске; остановленный диск может продолжать тарифицироваться. Перед новым запуском согласовать расход GPU. После разрешённого запуска:

```bash
brev start hatama-ml-gpu
ssh hatama-ml-gpu 'sudo systemctl status hatama.service --no-pager'
ssh -N -L 18000:127.0.0.1:8000 hatama-ml-gpu
```

Открыть `http://127.0.0.1:18000`. После изменений кода пересобрать frontend на сервере и выполнить `sudo systemctl restart hatama.service`. Повтор настоящего аудио-прогона (создаёт новые встречи):

```bash
cd /home/ubuntu/hatama/frontend
export PATH=/home/ubuntu/tools/node-v22.16.0-linux-x64/bin:$PATH
node server-validation.mjs
```

Остаются: ручная оценка ASR/говорящих/поручений, отдельные RU/KZ/RU-KZ аудио, визуальная проверка DOCX. Дополнительный новый прогон текстового Qwen после распоряжения об остановке не выполнялся. Токен Telegram, отправленный в чат, владельцу следует перевыпустить в BotFather и заменить в серверном `.env`.
